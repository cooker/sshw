WHY SSHW

把连接信息写一次，之后只需搜索和选择

sshw 读取 YAML 或 ~/.ssh/config，自动处理用户、端口、密钥、密码、SSH Agent、跳板机和登录后命令。

01

少记命令

使用别名直连，或从交互列表中选择目标，不再重复输入完整的 SSH 参数。

02

容易整理

按团队、环境或网段建立嵌套分组，大量 Server 也能保持清晰。

03

灵活认证

支持密码、私钥、Passphrase、SSH Agent 和 Keyboard Interactive。

04

本地管理

Config Web 默认只监听本机地址，保存时使用安全的原子替换流程。

QUICK START

三步打开第一个 SSH 会话

先创建配置，再添加 Server，最后运行 sshw。

1

创建配置文件

sshw 会按顺序查找用户目录和当前目录中的 .sshw、.sshw.yml 与 .sshw.yaml。

touch ~/.sshw.yaml
2

添加一台 Server

name 用于展示，alias 用于快捷连接。User 和 Port 可以省略。

- name: development
  alias: dev
  host: 192.168.8.35
  user: appuser
  port: 22
  keypath: ~/.ssh/id_rsa
3

选择或直接连接

不带参数时打开交互选择器。知道 Alias 时，可以直接连接。

sshw 交互选择 sshw dev Alias 直连

CONFIG REFERENCE

常用配置字段

Server 是普通节点；Group 是带有 children 数组的节点。

字段作用默认值
name选择器中的显示名称—
aliassshw <alias> 快捷连接—
host主机名或 IP 地址—
userSSH 用户名root
portSSH 端口22
keypath私钥路径，支持 ~—
agentpathSSH Agent Socket 路径—
jumpJump Host 定义—
children嵌套 Server 或 Group—
callback-shells登录后发送的命令—

配置文件查找顺序

  1. ~/.sshw
  2. ~/.sshw.yml
  3. ~/.sshw.yaml
  4. ./.sshw
  5. ./.sshw.yml
  6. ./.sshw.yaml

找到第一个存在的文件后停止查找。

- name: production
  children:
    - name: api-1
      alias: api
      user: deploy
      host: 10.20.0.11
    - name: worker-1
      user: deploy
      host: 10.20.0.12
- name: app via bastion
  alias: app
  user: appuser
  host: 192.168.8.35
  keypath: ~/.ssh/id_rsa
  jump:
    - user: ops
      host: bastion.example.com
      port: 2222
      keypath: ~/.ssh/bastion_rsa
- name: dev with startup commands
  alias: dev
  host: 192.168.8.35
  callback-shells:
    - { cmd: "cd /srv/app" }
    - { delay: 1500, cmd: "docker ps" }

BUILD

本地编译与交叉编译

build.sh 会注入版本信息，并把不同平台的产物放入独立目录。

# 当前平台
./build.sh

# Linux AMD64
GOOS=linux GOARCH=amd64 VERSION=dev ./build.sh

# 自定义输出目录
OUTPUT_DIR=/tmp/sshw-build ./build.sh
GOOS目标操作系统
GOARCH目标 CPU 架构
VERSION写入二进制的版本
OUTPUT_DIR产物根目录

FAQ & SAFETY

常见问题与安全提示

可以继续使用原来的 YAML 配置吗？

可以。新版保持现有 YAML 字段和结构兼容，Config Web 只是提供另一种编辑方式。

Config Web 会暴露到公网吗？

默认不会。服务监听 127.0.0.1:7899，仅本机可访问。不要随意绑定公开网络地址。

搜索没有结果后需要重新运行吗？

不需要。可以继续输入或按 Backspace 回退，结果会即时恢复。

可以把密码写进公开仓库吗？

不要提交真实密码、Passphrase、私钥或生产主机信息。优先使用私钥或 SSH Agent。
